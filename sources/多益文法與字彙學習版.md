# A. Part 5 先做的文法判斷

## 1. 詞性：最快的得分點

### 秒判規則

| 線索 | 常見答案 |
| --- | --- |
| 冠詞 `a/an/the`、所有格、形容詞後 | **名詞**：the *proposal* |
| `be` 動詞、連綴動詞（seem, become, remain）後 | **形容詞／名詞補語**：is *available* |
| 名詞前，用來說明名詞 | **形容詞**：a *successful* campaign |
| 動詞、形容詞、另一副詞後 | **副詞**：respond *promptly* / highly *effective* |
| 助動詞（will, can, must）後 | **原形動詞**：will *increase* |

### 常見字族

| 動詞 | 名詞 | 形容詞 | 副詞 |
| --- | --- | --- | --- |
| succeed | success | successful | successfully |
| decide | decision | decisive | decisively |
| compete | competition | competitive | competitively |
| apply | application | applicable | — |
| respond | response | responsive | responsively |

**易錯提醒：** `be + p.p.` 不一定是被動，也可能是形容詞狀態：`The store is closed.`（店是關著的。）

---

## 2. 主詞與動詞一致（Subject–Verb Agreement）

| 主詞型態 | 動詞判斷 | 例句 |
| --- | --- | --- |
| each / every / either / neither + 單數名詞 | 單數 | Each employee **is** required to attend. |
| either A or B / neither A nor B | 靠近動詞的主詞決定 | Neither the manager nor the assistants **are** available. |
| a number of + 複數名詞 | 複數 | A number of customers **have** complained. |
| the number of + 複數名詞 | 單數 | The number of customers **has** increased. |
| one of + 複數名詞 | 單數 | One of the files **is** missing. |
| 主詞後夾介系詞片語 | 看真正主詞 | The list of items **is** attached. |

---

## 3. 時態：先找時間線索

| 時態 | 結構 | 常見線索／用途 |
| --- | --- | --- |
| 現在簡單 | V / V-s | 習慣、事實、時刻表：The train **leaves** at 8. |
| 現在進行 | am/is/are + V-ing | 正在進行、暫時安排：We **are meeting** tomorrow. |
| 過去簡單 | V-ed | 明確過去時間：last week, in 2025 |
| 過去進行 | was/were + V-ing | 過去某時正在進行：I **was reviewing** the report when she called. |
| 現在完成 | have/has + p.p. | 過去至今、經驗、未明確時間：already, yet, since, for |
| 過去完成 | had + p.p. | 過去兩件事中「更早」的一件：The meeting **had ended** before I arrived. |
| 未來 | will + V / be going to + V | 預測、決定、計畫 |
| 未來完成 | will have + p.p. | `by + 未來時間` 前已完成 |

### 必背兩條

1. `when / before / after / as soon as / until / if` 引導的**時間或條件子句**，談未來時通常用現在式。  
   `We will begin when everyone arrives.`（不是 *will arrive*）
2. `since + 起點`、`for + 一段時間` 常搭配現在完成式。  
   `She has worked here since 2022.`

**精準修正：** 過去完成進行式（`had been V-ing`）強調「在某個過去時間點以前已持續一段時間」，不表示該動作仍持續到現在。  
`He had been waiting for an hour when the bus arrived.`

---

### 補充：狀態動詞與瞬間動詞

| 類型 | 代表動詞 | 多益常見規則 | 例句 |
| --- | --- | --- | --- |
| **狀態動詞** | know, believe, own, belong, understand, need, prefer | 通常不用進行式 | `We know the client well.`（非 *are knowing*） |
| **短暫行為** | be, think, have | 視語意可用進行式 | `He is being unreasonable.`（暫時表現） |
| **瞬間動詞** | buy, borrow, arrive, leave, begin, die | 不直接搭配 `for + 一段時間` 表持續 | `She has owned the car for two years.`（非 *has bought*） |

常見轉換：`die → be dead`、`buy → have/own`、`borrow → keep`、`join → be a member of`。  
`He has been a member of the club for three years.`（他入會已三年。）

---

## 4. 主動與被動（Passive Voice）

### 核心公式

`受詞 → 主詞 + be（依時態變化）+ p.p. (+ by + 執行者)`

| 主動 | 被動 |
| --- | --- |
| The staff **process** orders. | Orders **are processed**. |
| The staff **processed** orders. | Orders **were processed**. |
| The staff **will process** orders. | Orders **will be processed**. |
| The staff **has processed** orders. | Orders **have been processed**. |
| The staff **is processing** orders. | Orders **are being processed**. |

### 秒判規則

- 空格後有受詞：優先想**主動動詞**。`The team completed the project.`
- 主詞是「被處理的事物」：優先想**被動**。`The project was completed.`
- 助動詞後的被動：`must / can / should + be + p.p.`
- 命令／建議句型的被動：`suggest that S (should) be + p.p.`

---

## 5. 連接詞、介系詞、關係詞：看空格後面

| 空格後的結構 | 選擇方向 | 例句 |
| --- | --- | --- |
| **完整子句**（S + V） | 連接詞：because, although, if, while | We postponed it **because the vendor was late**. |
| **名詞／V-ing** | 介系詞：because of, despite, during, while | We postponed it **because of the delay**. |
| 缺主詞或受詞的子句，修飾前面名詞 | 關係代名詞：who, which, that | the report **that we submitted** |
| 子句完整，只補充時間／地點／原因 | 關係副詞：when, where, why | the day **when we met** |

### 高頻對照

| 連接詞 + 子句 | 介系詞 + 名詞／V-ing |
| --- | --- |
| because | because of / due to / owing to |
| although / though | despite / in spite of |
| while | during |

### 關係子句最小規則

- 人：`who`；事物：`which`；人或事物的限定資訊：`that`。
- 逗號後的非限定子句**不能用 `that`**。`Mr. Lee, who leads the team, ...`
- 受格關係代名詞可省略：`the file (that) I sent`；主格不可省略。
- `whose` 可修飾人或事物：`a company whose profits increased`。

## 6. 冠詞、量詞與代名詞

| 情況 | 用法 | 例句 |
| --- | --- | --- |
| 單數可數、首次提及 | a / an | an applicant |
| 特定、前文提過、獨一無二 | the | the applicant / the Internet |
| 複數或不可數，泛指 | 不加冠詞 | Employees need training. |
| 可數複數 | many / few / fewer | fewer errors |
| 不可數 | much / little / less | less equipment |
| 可數與不可數皆可 | some / any / a lot of | some information |

**易錯提醒：** `information, equipment, furniture, advice, luggage` 都是不可數名詞，不用 `an` 或複數 `-s`。

---

## 7. 比較級、最高級與平行結構

| 考點 | 公式 | 例句 |
| --- | --- | --- |
| 比較級 | -er / more + adj + than | more efficient than the old system |
| 同級比較 | as + adj/adv + as | as quickly as possible |
| 倍數 | twice as + adj + as | twice as large as ours |
| 最高級 | the + -est / most + adj | the most reliable supplier |
| 平行結構 | A, B, and C 詞性一致 | planning, testing, and launching |

`not only A but also B`、`either A or B`、`both A and B` 的 A、B 形式要平行。

# B. 動詞非謂語與特殊句型

## 8. Gerund（V-ing）與 Infinitive（to + V）

### 先背固定搭配

| 後接 V-ing | 後接 to + V |
| --- | --- |
| avoid, enjoy, finish, consider, suggest, recommend, postpone, mind, admit | decide, plan, hope, promise, refuse, agree, expect, afford, manage |
| look forward to, be used to, object to, contribute to | want, would like, need, fail, tend |

> `to` 若是**介系詞**，後面接 V-ing：`look forward to meeting you.`  
> `to` 若是不定詞符號，後面接原形動詞：`plan to meet you.`

### 語意不同的高頻動詞

| 動詞 | to + V | V-ing |
| --- | --- | --- |
| remember | 記得要做 | 記得做過 |
| forget | 忘記要做 | 忘記曾做過 |
| stop | 停下來去做另一事 | 停止正在做的事 |
| try | 努力設法做成 | 試試某種方法 |
| regret | 遺憾地通知／做 | 後悔做過 |

### `used to` 三兄弟

| 結構 | 意義 |
| --- | --- |
| used to + V | 過去常做，現在已非如此 |
| be used to + V | 被用來做… |
| be / get used to + N / V-ing | 習慣於／逐漸習慣… |

## 9. 分詞與分詞構句

| 形式 | 判斷 | 例子 |
| --- | --- | --- |
| V-ing | 主動、進行、令人… | a **growing** market / an **interesting** proposal |
| p.p. | 被動、完成、感到… | a **revised** schedule / **interested** clients |
| to be + p.p. | 尚未發生的被動 | documents **to be submitted** |

### 分詞構句

只有在兩子句**主詞相同**時才能縮減：

`Because the manager was concerned, she called a meeting.`  
→ `Concerned about the issue, the manager called a meeting.`

**易錯提醒：** 分詞片語的邏輯主詞必須是主句主詞；避免 dangling modifier。  
❌ `Driving to work, the rain began.`（雨不會開車）

---

## 10. 建議、要求與假設語氣

### should 省略（mandative subjunctive）

`suggest / recommend / demand / require / insist + that + S + 原形動詞`

- `The director recommended that the proposal be revised.`
- `It is essential that all visitors wear identification badges.`
- 否定：`They requested that the report not be released.`

### If 條件句

| 類型 | If 子句 | 主句 |
| --- | --- | --- |
| 真實／未來可能 | 現在式 | will / can / may + V |
| 與現在相反 | 過去式（正式英文常用 were） | would + V |
| 與過去相反 | had + p.p. | would have + p.p. |

`If I were you, I would accept the offer.`  
`Had we known earlier, we would have acted sooner.`（省略 if 的倒裝）

# C. 商務字彙：以搭配記，而非單字翻譯

## 11. 費用與金錢

| 字彙 | 中文與使用情境 | 常見搭配 | 商務例句 |
| --- | --- | --- | --- |
| **price** | 價格、售價；多指商品標價 | list price, retail price, price increase | `The price of the new model will be announced next week.`<br>新型號的售價將於下週公布。 |
| **cost** | 成本、費用；也可作動詞「花費」 | production costs, labor costs, reduce costs | `The company reduced production costs by automating the process.`<br>公司藉由自動化流程降低生產成本。 |
| **charge** | 服務費、額外收費；也可作動詞「收費」 | service charge, delivery charge, charge a fee | `There is no additional charge for installation.`<br>安裝不另收費。 |
| **fee** | 專業服務、註冊、入場等費用 | registration fee, legal fee, annual fee | `Please pay the registration fee by March 10.`<br>請於 3 月 10 日前繳交報名費。 |
| **rate** | 費率、比率；依時間／標準計算的價格 | room rate, interest rate, hourly rate | `The hotel offers a discounted room rate to conference attendees.`<br>飯店為與會者提供優惠房價。 |
| **fare** | 交通票價 | bus fare, airfare, round-trip fare | `Airfare is not included in the tour package.`<br>旅遊套裝行程不含機票。 |
| **toll** | 道路、橋梁通行費 | pay a toll, toll road, toll-free | `Drivers can pay the toll electronically.`<br>駕駛可用電子方式支付通行費。 |
| **reimbursement** | 報銷款、償還款 | claim reimbursement, travel reimbursement | `Submit the receipts to claim reimbursement for travel expenses.`<br>請提交收據以申請差旅費報銷。 |
| **deposit** | 訂金、押金；也可指存款 | security deposit, make a deposit | `A 30 percent deposit is required to confirm the reservation.`<br>須支付 30% 訂金才能確認預訂。 |
| **refund** | 退款；也可作動詞「退款」 | request a refund, full refund, refund policy | `Customers may request a full refund within 30 days.`<br>顧客可在 30 天內申請全額退款。 |
| **budget** | 預算；也可作動詞「編列預算」 | annual budget, stay within budget, budget for | `The marketing team must stay within its annual budget.`<br>行銷團隊必須控制在年度預算內。 |

## 13. 易混字：一定要連同句型記

| 字彙 | 詞性／中文／用法 | 常見搭配 | 例句 |
| --- | --- | --- | --- |

| **affect** | 動詞：影響 | affect sales / performance | `The strike affected delivery schedules.`<br>罷工影響了交貨時程。 |
| **effect** | 名詞：效果、影響；`have an effect on` | positive effect, take effect | `The new policy will take effect in July.`<br>新政策將於七月生效。 |
| **accept** | 動詞：接受 | accept an offer / payment | `We accept all major credit cards.`<br>我們接受所有主要信用卡。 |

| **economical** | 形容詞：節省的、經濟實惠的 | economical to operate | `This model is economical to operate.`<br>此型號的使用成本很省。 |
| **late** | 形容詞／副詞：遲的／晚地 | be late for, arrive late | `The train arrived late because of the storm.`<br>火車因暴風雨晚到。 |
| **lately** | 副詞：最近 | have + p.p. + lately | `Have you spoken with Ms. Lin lately?`<br>你最近有和林女士談過嗎？ |

## 16. 多益高頻慣用語與成語

> **重要度說明：** 多益不太會只考「冷門成語的中文意思」，但會把慣用語放在電子郵件、會議、協商與公告中測驗語意。因此以**商務語境、固定搭配與正式程度**來記最有效。`★` 為特別值得優先掌握的商務用語。

### 16.1 會議、溝通與專案

| 慣用語 | 中文與使用提醒 | 商務例句 |
| --- | --- | --- |
| **★ in a nutshell** | 簡言之；用於濃縮摘要 | `In a nutshell, the proposal will reduce costs.`<br>簡言之，這項提案將降低成本。 |
| **★ touch base with + 人** | 和某人簡短聯繫、確認狀況；比正式的 `contact` 口語 | `I will touch base with you after the meeting.`<br>會後我會和你簡短確認。 |
| **★ give someone a heads-up** | 事先提醒／預先告知某人 | `Please give the IT team a heads-up before the update.`<br>更新前請先通知資訊團隊。 |
| **★ stay on top of + N** | 持續掌握進度或資訊 | `The manager stays on top of the project's progress.`<br>經理持續掌握專案進度。 |
| **★ take the initiative** | 主動採取行動 | `She took the initiative to contact the supplier.`<br>她主動聯絡供應商。 |
| **★ have the floor** | 擁有發言權；會議主持人常用 | `Ms. Patel has the floor to present the budget.`<br>Patel 女士現在有發言權來說明預算。 |
| **carry the ball** | 承擔主要責任、主導推動 | `Jason will carry the ball on the client proposal.`<br>Jason 將主導客戶提案。 |

| **you lost me** | 我聽不懂／你說得太複雜了；非正式 | `You lost me at the technical details—could you explain them more simply?`<br>技術細節那段我聽不懂，能說得更簡單嗎？ |

# D. 題目判斷檢查清單

1. 先找句子的**主詞與主要動詞**。
2. 判斷空格要的是**詞性**還是**句子連接成分**。
3. 若是動詞，確認**時態、單複數、主被動**。
4. 若有 `to`、`-ing`、`p.p.`，確認是固定搭配還是修飾關係。
5. 最後用語意與常見搭配排除。
