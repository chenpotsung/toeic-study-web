# TOEIC 互動自學教材 Web 版

目前版本：v2.0 學習儀表板版

## 本版首頁設計

首頁已改成「今日學習儀表板」，不再放置容易被誤認或重複的浮動快捷按鈕。

系統會依照目前進度安排單一、清楚的下一步：

1. 完成 1 個建議章節。
2. 完成今日 10 題練習。
3. 練習結束後整理錯題。

首頁只保留一個主要行動按鈕，會依進度自動變成「開始今日章節」、「完成剩餘題目」或「開始錯題複習」。

## 直接離線使用

雙擊：

`TOEIC自學教室_單檔版.html`

所有教材、題庫、樣式與功能都放在同一個 HTML 檔案內。

## 部署到 GitHub Pages

請把本資料夾內的檔案全部上傳到 GitHub Repository 的最外層，確保 Repository 首頁直接看得到：

- `index.html`
- `styles.css`
- `data.js`
- `app.js`

接著前往：

`Settings → Pages → Deploy from a branch → main → /(root) → Save`

不要只上傳 ZIP，也不要讓結構變成 `toeic-study-web/toeic-study-web/index.html`。

## 學習紀錄

進度使用瀏覽器 `localStorage` 儲存：

- 同一個網址、同一個瀏覽器會保留進度。
- 本版沿用原本的儲存名稱，更新後既有章節、答題及錯題紀錄會保留。
- 新增每日作答數、當日完成章節及錯題複習數紀錄。
- 不同瀏覽器或不同裝置不會自動同步。
- 清除瀏覽器網站資料可能會清除進度。

## 檔案說明

- `index.html`：網站首頁與版面結構
- `styles.css`：視覺與手機版樣式
- `data.js`：22 個教材章節、85 題練習、40 張單字卡
- `app.js`：今日任務、進度、練習、錯題本、搜尋與單字卡功能
- `TOEIC自學教室_單檔版.html`：可直接離線開啟的單檔版
- `TOEIC自學教室_學習儀表板版.html`：同內容的辨識用檔名
- `REVIEW_LOG.md`：完整檢查及修正紀錄
- `sources/`：原始教材資料
